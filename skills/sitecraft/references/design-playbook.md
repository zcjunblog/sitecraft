# 从业务内容到具体画面

这里提供判断方式，不提供所有网站都要套用的成品模板。

新建或整体重做时结合 [visual-selection.md](visual-selection.md)：查看实际参考，必要时比较真实首屏小样。外部品牌实图见 [visual-benchmarks.md](visual-benchmarks.md)，实际成品与失败反馈见 [visual-cases.md](visual-cases.md)；只借鉴内容与构图关系，不复制品牌外观。

## 先选表达，再选外观

从访问者最需要看到的证据出发：

| 内容与任务 | 可尝试的视觉组织 | 容易失手的地方 |
| --- | --- | --- |
| 工具与软件：理解用途并试用 | 把真实工作流、可用小演示或界面细节做成视觉中心 | 用假仪表盘、乱码截图、无关球体代替产品 |
| 建筑、摄影与设计作品 | 让摄影占主要面积，项目索引、图注、网格对齐提供秩序 | 图片被塞进小卡片，装饰抢过作品 |
| 有品牌角色的创作者 | 角色参与与业务相关的场景，文字和操作形成清楚分工 | 整页都是吉祥物，反而看不出业务 |
| 专业服务与机构 | 清晰的服务边界、过程和真实证据，规整而有辨识度的排版 | 用假客户、假数字和权威标记制造可信感 |
| 导航、下载与单一任务页 | 主操作居中或在明确焦点，次要入口保持安静 | 硬塞介绍、愿景、评价，把任务入口挤走 |

这些不是行业限定。客户指定的风格和真实材料优先；同一行业也应有不同表达。

## 自动选择表达方案

新建或整体重做官网以沉浸式作为默认起点，不等用户补充该关键词。先决定让人进入什么主题、空间、产品或观看过程，再用下列表达帮助主要任务；不是在缺少偏好时退回通用横幅加卡片，也不是给所有行业套同一全屏皮肤。明确的其他方向、忠实复刻与局部修复优先遵从。

先确定访问者此刻最需要完成的动作与看到的证据，再判断主题和素材能支持哪种观看方式。颜色与字体在这个决定之后落实。内部留下简短依据即可：**访客要做什么 → 哪些内容值得突出 → 因此怎样组织画面与入口**，无需让用户先选风格。

| 表达方式 | 适用依据 | 首屏应兑现什么 |
| --- | --- | --- |
| 操作与信息优先 | 查找、比较、下载、预约等是主要目的 | 实际内容、筛选或业务入口直接可用，视觉秩序帮助操作 |
| 编辑与策展 | 作品、专题或观点有可读的选取关系与顺序 | 用图文尺度和留白带出主题，同时能继续浏览 |
| 场景沉浸 | 进入一个空间、世界观或故事本身有价值，且素材能支撑 | 画面、排字、观看进程与操作属于同一场景；按 [immersive-experiences.md](immersive-experiences.md) 实现 |
| 产品演示 | 界面、实物、工作流或变化过程最能说明价值 | 展示真实细节或可用演示，而非无关氛围图 |
| 服务与证据叙述 | 服务边界、可靠依据、过程与联系决定信任 | 具体服务、可核实证据与下一步清楚，构图仍可有个性 |

这是可组合的表达方式，不是五套固定页面、必须展示的选项或按行业查表。比如同一个海边美术馆，可以用白底策展承托藏品，也可以让某一专题沉浸展开；今日营业时间与购票仍需易找。工厂面向采购时可先呈现能力和询价，讲述制造过程时也能使用空间叙事。主题相同而访问目的不同，方案应随之改变。

默认直接完成主题相符的沉浸体验，同时保留核心任务；它可以是日光、实景、排字或可探索的产品，不等于暗色动画插画。比如鲜花门店可用明亮花材和自然光形成场景，采购官网可近看真实工艺与设备，作品集可让作品延展到观看空间；配色与结构不机械照抄。若素材不支持全屏场景，用成立的排版、图形或产品交互建立观看关系，不靠放大低质量图片、拉长空屏或增加生图数量填补。搜索、价格、票务、预约等关键内容仍直接可达。

## 把方向变成布局依据

开工前在内部工作笔记写清楚下列关系，无需用户先写简报、另做长文档或等待例行审批；一句话业务描述也应能开始并完成制作：

- **页面角色与动作**：访问者在介绍、浏览、比较还是直接操作；首屏要出现的实际内容和入口是什么。
- **材料特征**：哪些图、文字、产品界面或数据足以支撑画面；缺少什么，会怎样影响布局。先查看实际素材，不能只凭文件名想象。
- **可见决定与理由**：主次尺度、图片裁切、信息密度、对齐或浏览方式如何响应任务和材料。说明为何保留或省去横幅、卡片、标题等主要区域。
- **表达边界**：哪些元素承担识别或气氛，哪些必须退后。动效改变什么状态、引导什么注意力；不能只写“高级、沉浸、丝滑”。

优先读取用户提供的页面、截图及项目素材。新品牌缺少参考时，按视觉选择流程由执行者查看相关真实作品并自选方向；分析构图与素材完成度，而非只提取颜色。访问受限时用可用材料继续并注明缺口，不编造已浏览的参考。内部小样与适合任务的参考一同比较；用户没要求选方案时不将选风格变成开工条件。

**检查的是内容与形式的关系，不是强求处处新奇。** 去掉站名后，若连页面在做什么也说不清，或者整套区块可直接换成无关业务，应重新检查内容和层级。筛选条、图库、预约表单等成熟结构本来就可以复用；不能为了独特而降低可用性。颜色、圆角和字体相似本身不构成失败。

用户明确给出视觉方向时，将其转换为当前项目的具体比例、主体、颜色、字体与材质选择，再从首屏延续到全部区块。沉浸式描述观看体验，“简约大气”“明亮浪漫”等描述视觉取向，两者应共同成立。整页完成后按 [visual-review.md](visual-review.md) 做内部视觉修订，不把漂亮首图接通用内容区当作最终结果。

## 品牌依据：让界面与内容属于同一个世界

为新品牌或整体重做，在内部给出一条可追溯的关系：**内容或场景特征 → 配色/字标/标题的具体决定 → 首屏可见结果**。不是每项都需要原创资产，但不能只写“有品位、年轻、温暖”。

- **颜色**：说明底色、文字色和强调色为何适合这个概念，以及如何与影像共同工作；可以来自素材、行业语境或既有品牌。不要自动把暖白、炭黑、荧光强调色当成所有项目的安全答案，也不要求所有页面从图片机械吸色。
- **字标与字体**：已有 Logo/CI 优先保留。需要暂拟品牌时，选择能支持概念的字形、比例、组合或原创简洁符号；小尺寸仍可识别。通用符号、普通粗体与小号英文组合本身不构成品牌设计，必须有具体理由；不可为独特把中文字形改到难以辨读。
- **标题**：用真实业务、使用场景或品牌主张表达内容。若标题连同构图都可不加修改地用于摄影、健身和 AI 工具等无关业务，就检查其信息贡献；不要默认给泛化口号最后两个字加亮色划线。用户已确定的文案与风格优先，不做词语黑名单。
- **图像与界面**：检查字标、背景、按钮、分隔与图片裁切是否共享同一表达。图片可以是主体，但不应独自承担全部主题识别；换一张行业图就能变成另一个行业的整套界面时，需要重新处理品牌层。

首屏先做两次实际查看：正常渲染看整体气质；临时隐藏或遮住主图，仅作内部对照，看其余界面是否仍有承诺的品牌语言，并核对小尺寸字标与站标。第二次检查不是要求无图也必须辨认具体行业，而是暴露无依据的通用套件。不要把这项检查做成产品功能；最终恢复主图。

发现泛化时优先同时调整相关的底色、字标/字体和标题构图，而非只改一个色值或继续叠效果。没有参考也由执行者自行完成这些判断，不增加用户审批或要求用户给出品牌手册。局部修改和忠实复刻保留用户指定系统。

## 同一种内容，页面角色可以不同

以壁纸为例，两种方向都可能成立，不能由“壁纸站”三个字直接决定模板：

| 访问目的 | 构图依据 | 首屏检查 |
| --- | --- | --- |
| 快速挑选与下载 | 分类、尺寸与比例帮助比较；实际图片和可辨认的预览入口优先，轻量筛选与图库形成主体 | 是否已经能看到可挑选的图并开始筛选；宣传是否推迟了操作；不把所有混合题材强行调成同一色调 |
| 摄影专题与策展 | 有明确主题、选片顺序、作者或图注；大图与留白形成观看节奏，可用全幅影像主导 | 能否看出选片关系和策展主题；能否继续浏览或下载；大图是否只是随机照片加泛化口号 |

这是决策示例，不是两套必须照抄的布局。主任务明确时直接选择；用户指定沉浸体验时，设计真实的图像观看、切换与光影关系，不自动改成工具网格，也不只给原有模板叠流光。

## 先验证首屏，再扩展页面

用实际要交付的字体、内容和代表性素材完成首屏，按 [visual-review.md](visual-review.md) 的构图检查查看桌面与手机截图。此时就修正主任务、焦点、比例、裁切和素材问题，避免先复制十个区块再统一“美化”。不要把等待全部功能完成当成延后构图判断的理由。

这一检查由执行者完成，不是新的用户审批点；小改只检查受影响区域，用户指定的复刻或已确认结构优先。若无法渲染，记录未验证，不把书面简报视为画面已经成立。

## 五行视觉简报示例

任务：中文建筑事务所，四张实拍、三个案例名、地址电话。

- 目的：让委托人快速判断作品气质，找到联系方式。
- 证据：只有已核实的照片与名称，未知的年份、面积和奖项省略。
- 语气：安静、严谨、开放。
- 概念：一页可以浏览的建筑作品目录；一幅空间摄影主导首屏，项目序号与图注承担导航。
- 规则：照片原有色彩，低彩度底色，阅读清晰的中文字重；宽图与细节视角交替，排版沿同一条对齐线，不添加泛用功能图标。

简报应当能预测成品样子。若把品牌名换掉后几乎不用改变任何画面决定，方向可能还不够具体。不要为了不同而牺牲理解和使用。

## 素材策略

**已有好素材**：先看尺寸、清晰度、主体位置和权利范围。挑一张能建立气氛的主图，按视口分别裁切，保留人物、建筑等关键主体。对产品截图放大真正有价值的区域，不把不可读的整屏缩略图当证据。

**没有图但有产品**：直接呈现可核实的产品界面、工作流、文件、数据或可用演示。必要时构建有意义的 DOM/SVG 示例，并标识示例内容。

**只有名称和短文**：做排字、符号、结构或与业务有关的原创图形。页面可以短，视觉锚点可以是字体和空间。不要自动生成三个不存在的产品来填满“作品区”。

**素材是否撑得起主视觉**：按视觉选择流程对照实际参考。照片看光线、材质、构图与裁切；原创插画看造型、细节与统一语言；软件看真实工作流。简易书本、仪器或场景示意适合解释结构时可保留，但“能看出是什么”不能代替品牌主图的完成度。缺少精细材质时先解决素材或改成成立的排字，不靠渐变、纹理与动画给低细节物体加包装。

**确实需要生成图片**：构图提示包含主体、场景、镜头、光线、风格、色彩、主体占比，以及文字预留区。预先决定桌面和手机裁切；生成后亲自看图，不让正文、按钮、准确 Logo 或必要信息烧进图片。不要默认调用额外付费 API；使用现有工具能力和相关技能。

## 文字与空间

建立主标题、区块标题、正文、辅助说明四级左右的层级即可。正文的阅读舒适度比微型英文装饰更重要。

- 中文长标题按语义分行，少用手动 `<br>` 锁死所有屏宽；必要时在特定断点调整。实际检查一字孤行、标点悬空与不自然断句。
- 短标题可紧凑，中文正文需要舒展。行宽和行高共同决定密度，不只调字号。
- 一组内容的内部间距要小于组与组的间距。相同层级沿相同基线与对齐边，不靠肉眼逐个随意移动。
- 留白应说明分组和主次，不等于整页所有区域都留相同的巨大空隙。检查首屏后是否突然空了一整屏。
- 大标题不是唯一主视觉。窄屏避免让标题与装饰占完屏幕却看不到用途和主要操作。

下面仅展示“前景色绑定表面”的实现方式，不是推荐所有页面的配色模板：

```css
:root {
  --page: #f7f8fa;
  --ink: #1b2430;
  --action: #204d75;
  --on-action: #ffffff;
  --space: clamp(1.25rem, 3vw, 3rem);
}
body { color: var(--ink); background: var(--page); }
.section { padding-block: calc(var(--space) * 2); }
.button {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: .6em;
  min-block-size: 2.75rem;
  padding: .7em 1.2em;
  line-height: 1.3;
  color: var(--on-action);
  background: var(--action);
  border: 1px solid transparent;
}
.button svg { inline-size: 1.1em; block-size: 1.1em; fill: currentColor; }
.button:focus-visible { outline: 2px solid var(--ink); outline-offset: 3px; }
```

浅底次按钮、深底主按钮、图片上的浮动按钮需分别验证，不能只验证根元素的两个令牌。

## 有意识地使用常见效果

| 手法 | 有帮助时 | 退化为模板感时 |
| --- | --- | --- |
| 卡片 | 独立可操作对象、有边界的信息单元 | 每段话都套相同的圆角阴影 |
| 渐变与光晕 | 表达光线、空间或明确品牌气氛 | 和内容无关，只为填空 |
| 毛玻璃 | 背后有需要透出的真实层次，文字对比可靠 | 每层都模糊，层级和性能一起变差 |
| 大字号 | 标题简短且有明确内容，构图承受得住 | 空泛口号堆到占满首屏 |
| 图标 | 系统一致、意思明确，SVG 尺寸与笔画协调 | 混杂风格或用随机图案代替视觉素材；新增 Emoji 装饰仅限用户明确要求 |
| Three.js / 视差 | 空间展示本身有价值，并有低成本回退 | 只因“高级”而引入，内容被等待和动画阻挡 |

颜色、图像风格和材质不设全局禁用项，判断依据是它在这个页面里是否成立。新增 Emoji 的默认限制见 SKILL.md；控件、动效和光影的具体约束见 [motion-and-controls.md](motion-and-controls.md)。
