# 3D 网站

把空间感放在有内容依据的位置。先确定一个主角、访客能做的一个动作，以及这个动作能让人看懂什么。香水瓶旋转能露出瓶肩和盖子，宠物角色转头能回应访客，空间展览可以借景深交代展品之间的关系。让正文、导航、表单和主要按钮保持为真实 HTML。

## 选择实现

| 需求 | 实现 |
| --- | --- |
| “官网加点 3D 特效”，重点是层次和氛围 | 用 CSS `perspective`、`preserve-3d` 和不同深度的层做一个有前后关系的场景。为精细指针做克制的倾斜或视差，手机保留构图，可用轻触或明确按钮表达必要状态。 |
| 可拖动看侧面、鼠标跟随的模型、实时材质或立体粒子 | 使用真实 3D 渲染。纯静态项目优先原生 JavaScript 配 Three.js 或已有渲染器。先实现一个可用的视角和动作，再补灯光及转场。 |
| 已有 React Three Fiber、Three.js 或同类技术栈 | 沿用现有渲染器、加载流程与组件。依照项目约定静态导出。 |

新建或整体重做官网时主动判断主题是否适合一个 3D 主场景。用户只要局部精修或有明确平面方向时，沿用原范围。CSS 空间效果、静态渲染图和 WebGL 实时模型在交付说明中各按实际实现命名。用户要求看真实侧面时，验收要能从另一角度看到几何与遮挡。

## 先交付可用的首屏

1. 先写出能打开的 HTML，放好标题、主操作、静态主视觉和为场景预留的比例。优先用已有素材，一张主图即可开始写页面。有首屏静态视图后再加载渲染代码、模型和纹理。
2. 优先复用用户有权使用的本地资产。通用瓶型、抽象装置等能用基础几何表现时，直接建出原创模型。复杂角色优先验证模型可用、单位比例正确、需要的枢轴或骨骼存在。真实商品缺少必要资料时，通用模型应标明演示，避免冒充实物。
3. 先做到一个能操作的场景。为拖动、指针跟随或滚动转场设置限幅、缓动和可恢复的初始状态。重要的产品操作提供可聚焦的 HTML 控件。移动端手势让位于正常上下滚动。装饰性画布对辅助技术隐藏。
4. 成功绘制首帧后再切换到画布。WebGL 初始化失败、模型加载失败或上下文丢失时恢复静态主视觉，主要操作继续工作。减少动态效果时取消自动漂移、指针视差和滚动联动，按需求保留静帧或用户主动控制。使用需要 HTTP 的模块或 GLB 时说明预览方式。要求双击打开时，验证 `file://`；CSS 3D 和内联脚本可作为直接打开的实现。

## 控制成本与画面

- 首屏以一个主场景为起点。先定构图、主体比例、材质和光源方向，再决定是否加阴影、后处理或额外模型。背景粒子要能说明主题或引导视线。
- 模型优先用相对路径的 GLB，发布包带上实际使用的运行库、模型、纹理和解码器。仅在已有工具能验证画质和体积收益时增加模型压缩。真实 3D 所需的运行库缺失时，先保住静态视图，再检查现有渲染器或原生 WebGL 能否实现该场景。可行路径用尽时保留静态页面，并把真实 3D 标为未交付。
- 以容器尺寸而非整个窗口更新画布和相机。限制像素比，先以手机约 1–1.5、桌面约 1.5–2 为调试起点，再按画质和设备调整。静态或拖动型场景按需重绘。连续动效在场景离开视口或标签页隐藏时停帧，卸载时取消帧循环、观察器和监听，并释放几何、材质、纹理和渲染器。

## 验收与交付

- 桌面与手机分别看首屏和交互中间态。操作一次旋转或跟随、回到初始状态，再检查滚动、主操作和主体裁切。若交互是卖点，保留能看出实际状态变化的证据。
- 实际验证禁用 WebGL 或模型请求失败时的回退、减少动态效果偏好，以及无需 3D 即可使用的页面内容。工具缺失时保留可交付产物，并列出未验证项。
- 按 [静态发布检查](static-release.md) 分开记录首屏实际加载资源、额外 3D 资源和部署包体积。测速针对最终发布文件。现场查看 3D 效果使用静态站预览，在线部署不依赖常驻渲染服务。

## 实现参考

- [Sitecraft 的 Pawly 示例](https://github.com/zcjunblog/sitecraft/tree/main/examples/pawly) 展示本地 GLB、角色头部枢轴、指针反馈、首屏海报和静态部署。
- [CloudAI-X Three.js Skills](https://github.com/CloudAI-X/threejs-skills) 可按场景、镜头、材质或交互查阅实现。[Three.js GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html) 和 [WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html) 用于核对具体 API。
- [Immersive 3D Web](https://github.com/Flaeren/immersive-3d-web) 的场景构思与滚动叙事案例适合参考空间表达。[Three.js Product Skills](https://github.com/ahmettasdemirusa/threejs-product-skills) 提供产品查看器、配置器和模型优化的实例。
