# 参考资产与视觉迁移改造

用户已确认优先实施参考资产、参考到成品的视觉检查；本轮不运行生成任务、浏览器、A/B 或回归测试，全部优化完成后统一评估。

## 实现范围

- 以已有实际截图为证据，整理五种不同构图关系。每例包含来源/观察范围、适用与不适用条件、中文与手机改编、具体参数起点和原创 HTML/CSS 实现。参数是 Sitecraft 的实现建议，不冒充原站测量值。
- 用标准库脚本检索、导出项目设计计划并生成可改写的首屏骨架。第三方截图仅留在 QA 对照中，网站使用调用者提供的本地资产。
- 生成参考/当前截图并排的自包含对照页及哈希清单。视觉评审逐项记录构图、排字、主体、光线材质、行动与手机编排，保留问题、修订和复看证据。
- 接入现有 references/visual 阶段：缺少计划、对照、观察或未解决的视觉问题时不能登记通过。脚本只校验证据，审美判断仍须实际看图。
- 同步源 Skill、WorkBuddy 入口、README 和打包资源规则。保持七阶段、现有动效/性能/交付约束。

## 本轮核对与后续测试

本轮只核对修改内容、语法和文件引用，不运行新功能或测试套件，不更新安装目录或发布包。补充回归用例及后续验证清单，但不将其标为通过。

后续统一验证：五种骨架与独立外部参考路径、WorkBuddy 展平打包、错误证据阻断/修复复验、桌面手机对照及同素材盲评，再以新行业一句话任务验证选型。
